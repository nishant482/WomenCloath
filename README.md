# WomenCloath — Rang static React storefront

A responsive Indian ethnic-wear concept inspired by Odhni and Meena Bazaar, using blue, yellow, white and orange. Features 12 local product photographs, an expanded homepage, category and occasion sections, category filtering, search, price sorting, individual product pages, size selection, wishlist, shopping bag with quantity controls, and local form confirmations. No backend, checkout or real form submission is connected. State resets on reload.

## Pages and source files

- `/#/` — Home
- `/#/collections/all` — All 12 products
- `/#/collections/sarees`, `/#/collections/lehengas`, `/#/collections/kurta-sets`, `/#/collections/new-arrivals` — Category collections
- `/#/product/1` through `/#/product/12` — Individual product details
- `/#/about` — Our story
- `/#/contact` — Contact form preview and FAQs
- `/#/shipping` — Shipping information

Hash-based navigation supports direct links, reloads and browser back/forward on static hosts without server rewrites.

Edit `src/styles.css` and `src/pages.css` for styling, `src/main.jsx` and `src/pages.jsx` for layout, and `src/products.js` for the catalogue. Files in `dist/assets` are generated by the production build and should not be edited directly.

## Product filters

Home and collection pages support combined category, colour, fabric and price-range filters. Active filter chips can be removed individually; Clear all resets category, search and filter selections. The result count updates immediately and an empty state provides a reset action. Price sorting also applies to filtered results.

Filter UI and matching logic: src/product-filters.jsx and src/product-filters.css.

## Homepage and media

The expanded homepage and footer live in src/home-extras.jsx and src/home-extras.css. Audio/video routes, links, promotional sections and generated media files have been removed from the storefront. The optional-page registry is empty.

## Run

Install Node.js 20.19+ or 22+, then:

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Deploy the generated `dist` directory to any static host.

Reference sites: https://odhni.com/ and https://meenabazaar.com/collections/readytoship. Product photographs are downloaded from Odhni for this reference-based demonstration. Replace these with owned or licensed images before public commercial use. Google Fonts supplies DM Sans and Playfair Display; system fonts serve as fallbacks.
